مستندات API مدیانا (1.0.0)
Download OpenAPI specification:Download

API مدیانا خدماتی برای ارسال پیام‌ها از طریق کانال‌های مختلف از جمله پیامک، پیام‌رسان‌ها، ایمیل و VoIP ارائه می‌دهد.

شروع به کار
آدرس پایه: https://api.mediana.ir
احراز هویت با کلید API الزامی است
کلید API را در هدر X-API-KEY به صورت زیر وارد کنید: YOUR_API_KEY
